# v1.0.1 - Zenodo archival release

This patch release enables Zenodo archival after the repository integration was activated. It does not change the cohort definition, outcome, predictor set, model coefficients, analysis code, or public-data boundary.

Changes:

- corrected public-release status wording in the repository documentation;
- added the public GitHub repository URL to citation metadata;
- updated citation metadata to version `1.0.1`;
- retained the absence of patient-level MIMIC-IV data, predictions, credentials, and serialized model objects.

Zenodo assigns a version DOI only after it processes this GitHub Release.
